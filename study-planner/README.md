# 勉強ログ (2026年11月29日まで)

Safari対応の学習記録アプリ。平日4時間、土日祝8時間、計168時間。好きな科目と時間を記録すると残りのグラフが減ります。ブラウザ保存（localStorage）なので、同じブラウザ・同じURLで利用し、定期的にアプリ内のバックアップをダウンロードしてください。

GitHub Pagesをリポジトリ `main` / `(root)` から公開すると、URLは `https://kokoa3955.github.io/cocoa-labs/study-planner/` になります。GitHubの Settings → Pages で公開設定を確認してください。

学習期間: 2026-10-27 ～ 2026-11-29（両端含む）。11/28と11/29もカレンダー表示・勉強記録が可能。総目標168時間と既存の学習記録は変更しません。

ContextShelf の主な機能

  • 1秒で引用保存: Web上の文章を選択して Alt + S または右クリックするだけで、タイトルやURLと一緒にサイドパネルへ記録。
  • 場所ピン＆ジャンプ: 「📍場所」ボタンを押すと、元のWebページの引用位置まで自動スクロールし、赤色マーカーで示します。
  • Gemini 3.5 Flash-Lite 高速要約: 長い引用もワンクリックで2〜3行の箇条書きに要約。
  • 一言メモ＆テキスト編集: 「なぜ保存したか」の所感を残したり、引用文の不要な文字をその場で手直しできます。
  • Markdown / JSON 出力: 溜まったデータを一括ダウンロードし、外部エディタへ手軽に引き継げます。

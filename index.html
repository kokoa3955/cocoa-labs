ContextShelf の便利なところ

必要な機能だけをサイドパネルにまとめました。

⚡

選択して1秒で保存

テキストを選んで Alt + S を押すだけ。タイトルやURLも一緒にすぐ保存されます。

📍

元の場所にすぐ戻れる

「📍場所」ボタンを押すと元のWebページの保存した位置まで自動でスクロールし、赤色マーカーで示します。

✨

AIですぐ要約

長文の引用もワンクリックで2〜3行に要約。サッと内容を思い出せます。

💭

一言メモ＆文章の手直し

「なぜ保存したか」のメモを残せます。保存した引用文の余計な文字もその場で編集可能です。

📁

フォルダ・タグで整理

フォルダ分けやタグ付けができます。キーワード検索時は一致した部分が黄色く光って見つけやすいです。

📥

Markdown / JSON で保存

溜まったメモを一括でMarkdownファイルとしてダウンロード。自分のエディタにすぐ移行できます。

スクラップブックとAIの強みをブラウザサイドパネルに集約しました。

⚡

1秒で引用保存

テキストを選択して Alt + S または右クリック。ページタイトル、URL、引用文をDOMを汚さずにサイドパネルへ即座に記録します。

📍

場所ピン＆ジャンプ

「📍場所」を押すと元のWebページの該当位置まで自動スクロールし、淡い赤色マーカーでハイライト。引用の前後文脈をいつでも確認できます。

✨

Gemini 3.5 Flash-Lite要約

長文引用もワンクリックで2〜3行の箇条書きに要約。最速・低コストなFlash-Liteモデルにより、ストレスのない即時レスポンスを実現。

💭

一言メモ＆直接編集

引用ごとに「なぜ保存したか」の所感をメモ入力。さらに、引用テキストの不要な改行や余計な文字もその場で手軽に修正できます。

📁

フォルダ＆タグ分類

プロジェクト別のフォルダ振り分けや、#重要 などのタグ付けに対応。キーワード検索時はヒット箇所が黄色くハイライトされます。

📥

Markdown / JSON 出力

蓄積した引用とメモを一括でMarkdown形式でダウンロード。Text Fragmentリンク付きで外部エディタへもシームレスに引き継げます。

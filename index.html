Markdown Hub

In Development

ブラウザ上のあらゆるテキストをワンクリックで整形・Markdown構文へ変換する超軽量ユーティリティ。

ストレスゼロの研究・情報収集

スクラップブックと最新AIの強みをブラウザサイドパネルに集約しました。

⚡

1秒で引用保存

テキストを選択して Alt + S。ページタイトル、URL、引用文をDOMを汚さずに即座に記録します。

📍

場所ピン＆ジャンプ

「📍場所」を押すと元のWebページの該当位置まで自動スクロールし、淡い赤色マーカーでハイライト表示します。

✨

Gemini 3.5 Flash-Lite要約

長文引用もワンクリックで2〜3行の箇条書きに要約。最速・低コストなFlash-Liteモデルにより即時レスポンスを実現。

💭

一言メモ＆テキスト編集

引用ごとに「なぜ保存したか」の所感をメモ入力。引用文の不要な改行や余計な文字もその場で修正できます。

📁

フォルダ＆タグ分類

プロジェクト別のフォルダ分けや、#重要 などのタグ付けに対応。キーワード検索時はヒット箇所が光ります。

📥

Markdown / JSON 出力

蓄積した引用とメモを一括でMarkdown形式でダウンロード。Text Fragmentリンク付きで外部へシームレスに引き継げます。
